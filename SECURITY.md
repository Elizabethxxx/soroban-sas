# Security Policy

## Supported Versions

Currently, the project is in active development and has not reached a stable release. Security updates will be applied to the `main` branch. 

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please do not create a public issue. Instead, send an email to the repository maintainers. All security vulnerabilities will be promptly addressed.

Please see the comprehensive [Security Assumptions and Threat Model](docs/security.md) for more details on the scope of the project's security perimeter.
